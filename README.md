# Dodge Game

A simple beginner-friendly Dodge Game made using HTML, CSS, and JavaScript.

## How to Play

- Move the player using the keyboard.
- Avoid the falling obstacles.
- Try to survive as long as possible.
- Your score increases as you survive.

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Player movement
- Falling obstacles
- Collision detection
- Score system
- Game over system
- Restart option

## How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.
4. Start playing.

## Project

This project was created as a beginner coding project to practice HTML, CSS, and JavaScript.
